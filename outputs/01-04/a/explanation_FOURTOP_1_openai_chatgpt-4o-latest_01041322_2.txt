This script builds a fully-connected neural network classifier for classifying proton-proton collision events into signal vs background categories using PyTorch. The network architecture (ParticleNet) consists of several fully connected layers with batch normalization, ReLU activations, and dropout for regularization. The dataset is assumed to be loaded as provided PyTorch tensors with 106 features (94 for object features from zero-padded sequences + 2 for E_T_miss and its phi + 1 weight not used directly as input).

The model is trained with Adam optimizer minimizing binary cross-entropy loss, and we monitor validation AUC after each epoch. The model achieving the best AUC during training is saved to disk in an appropriately named file. A command-line argument `--dryrun` is implemented to perform a test of model instantiation and forward pass without training, allowing for basic validation.

This configuration focuses on simplicity and speed while remaining flexible for future augmentation with physics-inspired architectures like graph networks or permutation-invariant models. The input format supports variable-length objects thanks to zero-padding. A batch size of 1024 keeps the training memory efficient while retaining convergence stability. The AUC is evaluated using scikit-learn's `roc_auc_score` for consistent metric evaluation.
