This code implements a binary classifier for particle physics data, specifically for classifying four-top-quark events. Here's a breakdown of the approach:

1. Data Preprocessing:
   - The raw data contains event weights, missing transverse energy, and object properties.
   - I extract these features and organize them into a more structured format.
   - I apply a mask to handle zero-padded entries in the data.
   - I add engineered features like the log of missing transverse energy and the count of non-zero objects, which are valuable for physics analysis.

2. Model Architecture:
   - The model is a deep neural network with multiple linear layers.
   - It includes batch normalization to stabilize and accelerate training.
   - Dropout is applied for regularization to prevent overfitting.
   - ReLU activations are used for hidden layers, with a sigmoid for the output layer to get probabilities.

3. Training Approach:
   - Binary Cross-Entropy loss is used as it's appropriate for binary classification.
   - The Adam optimizer is used with weight decay for regularization.
   - A learning rate scheduler reduces the learning rate when progress plateaus.
   - The model is trained for 15 epochs with a batch size of 256.

4. Evaluation:
   - The model is evaluated using the AUC metric as specified in the problem.
   - I plot the training loss and validation AUC to monitor progress.
   - The final validation AUC is reported to assess model performance.

Physics Insights:
- The model treats each particle physics event holistically, considering both event-level features and individual object properties.
- By masking zero-padded entries, the model focuses on actual particles rather than padding artifacts.
- The architecture is designed to learn complex patterns in high-energy physics data.

This approach should effectively distinguish signal events (four top quarks) from background processes, maximizing the AUC metric as required.
