This solution uses a Transformer-based architecture for binary classification of particle physics events. The data includes a variable number of objects per event, and pairwise kinematic features such as invariant mass are computed using physics-informed transformations. The architecture consists of a Transformer encoder that processes a sequence of event features, followed by a classification layer. The model is trained with Binary Cross-Entropy (BCE) loss and optimized using Adam. The AUC metric is computed on the validation set to evaluate performance.
