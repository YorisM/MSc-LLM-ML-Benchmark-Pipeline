The code builds a Lorentz-invariant message passing neural network (MPNN) to maximize AUC for classifying rare four-top (signal) versus top+X (background) events in high-energy physics. The architecture parses the variable-length per-event object structure, transforms per-object kinematics (E, pT, eta, phi) to Lorentz four-vector Cartesian coordinates (E, px, py, pz), encodes object type via an embedding, and constructs message-passing layers that use explicitly Lorentz-invariant features (pairwise invariant mass, Minkowski dot products). Each node's features are updated via local (node) and relational (edge) functions. Global event-level and MET features are aggregated. The preprocessor derives statistics for normalization, masks out padded objects, and standardizes kinematics. The network is trained via BCEWithLogitsLoss and AdamW, with per-epoch accuracy and validation loss/auc tracking. By including equivariant layers and explicit Lorentzian tensor products (via the invariant mass), the model leverages high-level inductive bias for optimal rare-process discrimination, which is key for collider experiments like the LHC.
