This solution is designed to maximize AUC for the binary classification task of detecting four top quark events in particle physics data. Here's a detailed breakdown of the approach:

1. **Preprocessing**:
   - The `PreprocessModule` normalizes features with non-zero variance to ensure numerical stability and better convergence.
   - It identifies and handles padding in the sparse dataset, which is crucial since events can have variable numbers of objects.
   - Physics-aware feature engineering: I compute aggregated features like total energy sum and total transverse momentum (pT) sum across all particles, which are physically meaningful for distinguishing signal from background.
   - The preprocessing is implemented using only PyTorch operations to ensure TorchScript compatibility.

2. **Model Architecture**:
   - The classifier uses a deep neural network with residual connections to allow for better gradient flow during training.
   - I implemented residual blocks to help with the vanishing gradient problem in deeper networks while maintaining the ability to learn complex patterns.
   - The architecture progressively reduces dimensionality through hidden layers (512 → 256 → 128) before the final classification layer.
   - Batch normalization is applied after each linear layer to stabilize training.
   - Dropout is used for regularization, with a higher rate (0.3) in earlier layers and decreasing toward the output.

3. **Training Approach**:
   - I use Focal Loss instead of standard binary cross-entropy to better handle any class imbalance and focus training on hard-to-classify examples.
   - The Adam optimizer with a small weight decay (1e-5) helps prevent overfitting.
   - A learning rate scheduler (ReduceLROnPlateau) monitors validation AUC and reduces the learning rate when improvement plateaus.
   - The best model based on validation AUC is saved during training.

4. **Performance Optimization**:
   - Model parameters are carefully balanced to prevent overfitting while maintaining high expressivity.
   - Both accuracy and AUC metrics are tracked during training to ensure the model is learning effectively.

This solution specifically targets maximizing AUC by:

1. Using a loss function (Focal Loss) that aligns well with AUC optimization by focusing on correctly ranking examples.
2. Including physics-motivated features that help separate signal from background.
3. Employing a model architecture with sufficient complexity to capture the intricate patterns in high-energy physics data.
4. Implementing proper regularization techniques to ensure the model generalizes well to unseen data.

The approach should work well on the sparse, variable-length data characteristic of particle collision events while capturing the important physical relationships needed for effective classification.
