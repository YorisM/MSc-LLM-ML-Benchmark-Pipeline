This solution addresses the four tops classification problem with a focus on maximizing AUC. Here's a detailed explanation of the implementation:

1. Preprocessing (PreprocessModule):
   - The preprocessing module is designed to handle the complex structure of particle physics data with variable-length events.
   - It identifies features with non-zero variance to filter out padding values.
   - Applies normalization to numerical features to ensure stable training.
   - Handles the structured data format where each physics object has 5 features (object_id, E, p_T, eta, phi).
   - Separates header features (weight, E_T_miss, phi_miss) from object features.

2. Neural Network Architecture (Classifier):
   - Implements a neural network with multiple components optimized for physics data:
     a. Feature extraction layers to process the preprocessed input data.
     b. Self-attention mechanism that captures relationships between different physics objects in an event.
     c. Classification head that makes the final prediction.
   - Uses modern activation functions (GELU) and normalization techniques (LayerNorm) for better performance.
   - Implements dropout for regularization to prevent overfitting.

3. Training Pipeline:
   - Uses Binary Cross-Entropy loss function which is appropriate for binary classification problems.
   - Implements the Adam optimizer with weight decay for regularization.
   - Includes learning rate scheduling with ReduceLROnPlateau to adapt the learning rate based on validation performance.
   - Implements gradient clipping to prevent exploding gradients, which can be an issue in physics data.
   - Tracks multiple metrics including loss, accuracy, and specifically AUC (which is our target metric).
   - Implements early stopping by saving the best model based on validation AUC.

4. Physics-Aware Design Choices:
   - The self-attention mechanism allows the model to capture complex interactions between particles, which is crucial for identifying rare four tops events.
   - The preprocessing recognizes the physics-based structure of the data with objects and their properties.
   - The model architecture is designed to handle the sparse nature of collision data.

The solution achieves high AUC by focusing on the following key aspects:

1. Effective preprocessing that preserves meaningful physical information while normalizing features.
2. A model architecture that can capture complex relationships between particles.
3. Robust training with regularization techniques to prevent overfitting.
4. Direct optimization for the AUC metric by using the validation AUC for model selection and learning rate scheduling.

This approach leverages both physics knowledge and modern deep learning techniques to create an effective classifier for the four tops physics process.
