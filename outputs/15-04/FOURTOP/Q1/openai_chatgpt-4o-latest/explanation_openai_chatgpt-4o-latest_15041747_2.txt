This code builds a binary classifier for the four-top quark signal classification task using a PyTorch deep neural network. Data preprocessing uses standard normalization (StandardScaler) to handle numerical numerical instability and improve convergence. The Classifier model is a fully connected neural network with 2 hidden layers, batch normalization, dropout for regularization, and ReLU activations. The BCEWithLogitsLoss is used because the problem is binary classification and the model's final output is not passed through a sigmoid within the model (which is more stable numerically). During each epoch, AUC is computed using sklearn's roc_auc_score for both training and validation sets. Training and validation loss and AUC scores are plotted, and the model is saved after training.
