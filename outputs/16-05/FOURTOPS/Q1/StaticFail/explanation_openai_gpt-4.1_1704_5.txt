This code focuses on maximizing the AUC for the binary classification of LHC events by considering both domain-specific preprocessing and an expressive, regularized MLP. The preprocessor (PhysicsPreprocessor) automatically removes the object type integer indices from the input event arrays (which are not physically meaningful for classification since they're just enumeration) and standardizes the remaining features (excluding padded zeros), then applies 3-sigma clipping to limit the effect of outliers and preserve physical realism.

The model (ParticleMLP) is a deep MLP with batch normalization and dropout to reduce overfitting, but with enough capacity to model the rich, high-dimensional physics data (with per-object info, padded to max objects per event). AdamW optimizer and ReduceLROnPlateau scheduler are used for stable convergence. Training and validation accuracy and loss are tracked per epoch; accuracy uses a sigmoid threshold, and the loss is BCEWithLogitsLoss. All code is compatible with CPU and supports direct integration for efficient challenge workflow.

This setup leaves enough parameter headroom to fit the problem but is regularized not to overfit, while the batch-norm+dropout structure enables generalization and more stable convergence for AUC maximization. The preprocessing ensures maximal preservation and normalization of physics-relevant information.
