This solution is designed for robust, generalizable discrimination between four-top signal and complex backgrounds, with the goal of maximizing AUC as required by the challenge.\n\n-- Preprocessing --\nThe PhysicsEventPreprocessor extracts physics-motivated features from the raw, sparse, and variable-length inputs. For each event, it extracts:\n - Number of physical objects (jets/leptons with valid E, pT >0)\n - Scalar sum of pT (HT), ETmiss magnitude and its phi\n - Means and stds of (pseudo)rapidity and phi over present objects\n - Summary stats: max/min/mean/std for pT and E, and min angular separation (delta-R)\n - The per-event leading four objects' (E, pT, eta, phi)\nThis produces a compact, information-rich feature vector for each event (total length: 24), which should be highly AUC-effective yet minimizes overfitting/noise from padding. All features are standardized globally using sklearn's StandardScaler.\n\n-- Model --\nThe classification model is a compact multilayer perceptron (MLP) with batch normalization and dropout built for numerical features. Its layers are:\n Input (24) -> Linear(64) -> BN -> ReLU -> Dropout (0.2) -> Linear(32) -> BN -> ReLU -> Dropout (0.1) -> Linear(16) -> ReLU -> Output (1, logits)\nThis model is deep enough to capture moderate nonlinearity in the processed physics features but is compact (< 50 MB) and regularized for generalization.\n\n-- Training --\nThe model is trained using BCEWithLogitsLoss, Adam optimizer, and ReduceLROnPlateau scheduler (halves learning rate on plateauing validation AUC), for 25 epochs. Each epoch tracks train/val loss, accuracy, and (importantly) validation AUC; the best model parameters are checkpointed using the highest validation AUC and restored at the end.\n\nThis solution is computationally efficient and robust, minimizes the potential for overfitting due to variable-length sparse inputs, and uses domain-relevant event features carefully engineered for high AUC. It should deliver near-optimal discrimination of ttbar+X background from ttbar ttbar signal with the provided constraints.
