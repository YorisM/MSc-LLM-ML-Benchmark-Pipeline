This code implements a binary classifier for the four top quarks (tttt) classification task, with a focus on maximizing the AUC metric. Here's a detailed breakdown of the approach:

1. Data Preprocessing:
   - Handle missing values by replacing NaNs with zeros
   - Extract event weights for weighted loss calculation
   - Normalize features using StandardScaler
   - Create physics-inspired feature engineering:
     - Extract global event features (missing energy)
     - Reshape object features to maintain their structure
     - Create masks to identify valid objects
     - Derive new physical quantities like transverse mass (mT) and rapidity
     - Calculate global event features like HT (scalar sum of pT) and object count
   - Combine all features and create DataLoaders with weights

2. Model Architecture:
   - Implement a deep neural network with residual-style connections
   - Use batch normalization, leaky ReLU activations, and dropout for regularization
   - Initialize weights using Kaiming initialization for better convergence
   - The model gradually reduces dimensionality (512→256→128→64→1)
   - Final sigmoid activation for binary classification probabilities

3. Training Approach:
   - Use Binary Cross Entropy loss weighted by event weights
   - Implement AdamW optimizer with weight decay for regularization
   - Apply learning rate scheduling with ReduceLROnPlateau based on validation AUC
   - Track multiple metrics: loss, accuracy, and AUC
   - Implement gradient clipping to prevent exploding gradients
   - Save the best model based on validation AUC

4. Physics Considerations:
   - Respect the structure of the particle physics data (objects with properties)
   - Create physics-motivated derived features that help discrimination
   - Use event weights to account for the relative importance of different events
   - Handle the variable number of objects per event with masking

The implementation specifically targets the challenges of high energy physics data by:
1. Properly handling the sparse, variable-length nature of collision events
2. Incorporating domain knowledge through feature engineering
3. Maintaining the proper weighting of events based on their physical cross-sections
4. Optimizing directly for the AUC metric which is crucial for rare signal detection

The model architecture balances complexity with generalization ability, using regularization techniques to prevent overfitting to the training data while still capturing complex patterns in the high-dimensional feature space of particle collisions.
