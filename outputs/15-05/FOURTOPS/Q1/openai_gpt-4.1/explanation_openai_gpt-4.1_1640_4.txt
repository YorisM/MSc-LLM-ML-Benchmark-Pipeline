This code implements a robust preprocessing and deep neural network pipeline aimed at maximizing AUC in the four-top event classification task described.\n\n## Preprocessor\n- The processor (EventPreprocessor) handles the zero-padded variable-length event format.\n    - It detects where the physical objects are in each event (non-padded entries using pT!=0).\n    - It imputes missing values (due to padding) with the per-feature median value.\n    - Then standardizes (zero mean, unit variance) the features based on the unpadded entries.\n    - High-level features, namely the number of objects per event (n_obj) and sum of E of all objects (sum_e), are appended as new features, as such global quantities can help a neural network better distinguish signal from background.\n    - All operations are deterministic and the preprocessor is compatible with pickle serialization and sklearn API.\n\n## Model\n- The deep neural network is a four-hidden-layer feedforward net, using GELU activations and batch normalization at each layer.\n- Dropout regularization is applied after each dense layer to help prevent overfitting.\n- The final output layer is one neuron for binary classification; it outputs logits and requires sigmoid in evaluation (BCEWithLogitsLoss is used for numerical stability).\n\n## Training Loop\n- Uses AdamW optimizer (Adam with decoupled weight decay), with standard settings and minor weight decay.\n- Runs for 25 epochs (can be increased if performance plateaus).\n- Tracks per-epoch train and validation loss and accuracy for plotting/diagnostics.\n- Model is trained on GPU if available.\n- All logic, including moving data to device and converting labels, is handled per batch.\n\nThis code is directly pluggable into the provided challenge wrapper, and maximizes AUC by combining effective per-event feature handling, additional high-level features, and a proven deep learning architecture that can exploit the sparsity and raw structure inherent in high-energy physics datasets.\n
