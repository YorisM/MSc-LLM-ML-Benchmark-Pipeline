I've created a solution for binary classification of four-top quark events, focusing on maximizing AUC. Here's a detailed explanation of the approach:

1. **Data Preprocessing**:
   - Created a specialized `PreprocessModule` that understands the structure of high-energy physics events
   - Implemented smart feature masking to exclude zero-padded data, which would only add noise
   - Applied proper normalization using mean/std statistics calculated from non-zero values
   - Handled NaN and infinity values that might arise during preprocessing
   - Identified the structure of the dataset (weight, E_T_miss, phi_ET_miss followed by groups of particle objects)
   - Created functionality to track object start indices for potential future physics-based feature engineering

2. **Model Architecture**:
   - Implemented a deep neural network with 3 hidden layers (256→128→64 nodes)
   - Added batch normalization after each hidden layer to stabilize training
   - Incorporated dropout layers (30%, 30%, 20%) to prevent overfitting
   - Used LeakyReLU activations to allow for negative values and avoid dead neurons
   - Applied Kaiming initialization for weights to improve convergence with LeakyReLU

3. **Training Strategy**:
   - Used BCEWithLogitsLoss for numerical stability in binary classification
   - Implemented Adam optimizer with weight decay (1e-5) to regularize the model
   - Added gradient clipping to prevent explosive gradients
   - Incorporated learning rate scheduling with ReduceLROnPlateau based on validation AUC
   - Implemented early stopping with patience=5 to avoid overfitting
   - Saved the best model based on validation AUC
   - Tracked multiple metrics: loss, accuracy, and AUC for both training and validation sets

4. **Physics-aware Decisions**:
   - The preprocessing understands the physical structure of the data (events with variable numbers of particles)
   - Handled the sparsity of the dataset by focusing on non-zero values
   - Used proper data normalization for physics features, which is critical as different features (E, pT, eta, phi) have different scales

5. **Performance Optimization**:
   - Used batch size of 1024 for efficient GPU utilization
   - Added early stopping to prevent overfitting to the training set
   - Implemented learning rate scheduling to find the optimal convergence point
   - Used model checkpointing to save the best-performing model based on AUC

The solution is specifically designed to handle the challenges of particle physics data, including variable-length events, sparse representations, and the need for high discrimination power between rare signal processes and background noise.
